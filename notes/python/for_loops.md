# Python For Loops - June 11, 2026

## For Loop vs While Loop
- while loop: runs as long as condition is true
- for loop: iterates over every item in a collection

## Syntax
for item in collection:
	do something with item

## Key Concepts
- No exit condition needed
- Stops automatically when list is exhausted
- Variable name (device) is your choice
- f-string fills in variable value automatically

## Real World Use
- Loop through list of network devices
- Run same command on every device
- Process every item without manual counting
